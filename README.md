**IT-1 Pro** — Simplifying employee lifecycle management, IT operations, and logistics through a centralized platform.

## Overview

IT-1 Pro helps organizations manage employee lifecycle processes, IT operational workflows, reporting, and asset logistics in one place. It aims to standardize processes, improve operational visibility, and simplify day-to-day activities.

## Key Features

- **Employee Onboarding** — Manage employee onboarding activities and processes.
- **Employee Lifecycle Management** — Support employee-related processes throughout their employment.
- **Employee Exit Management** — Manage employee exit and offboarding processes.
- **SHR (Shift Handover Report)** — Manage shift handovers, operational updates, and pending tasks.
- **NTP Reports** — Manage and access NTP-related operational reports.
- **Workbook** — Support workbook-related activities and reporting.
- **Gate Pass Management** — Manage gate passes for asset movement and related logistics activities.
- **Shipment Tracking** — Track asset shipments and transfers between employees, vendors, and sites.
- **Centralized Platform** — Bring employee lifecycle, IT operations, reporting, and logistics workflows together in a single application.

## Technology Stack

- **Backend:** PHP
- **Database:** MariaDB
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

- PHP
- MariaDB
- Apache or another compatible web server
- A web browser

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/madhan1306/IT-1Pro.git
   ```

2. Move the project files into your web server's document root.
3. Create a MariaDB database for the application.
4. Configure the database connection using the application's configuration file.
5. Configure the web server and required PHP extensions.
6. Open the application in your browser and complete any required setup steps.

## Security

- Keep database credentials and other sensitive configuration details out of version control.
- Use appropriate authentication and access controls.
- Store environment-specific configuration securely.
- Configure the production environment securely.
